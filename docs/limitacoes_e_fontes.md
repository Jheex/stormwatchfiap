# Fontes, limitações e decisões

## Fontes utilizadas

- `dados_pluviometricos.csv` — cópia original recebida para o projeto.
- `dados_geotecnicos.csv` — cópia original recebida para o projeto.
- `dados_hidrologicos.csv` — cópia original recebida para o projeto.

Registrar aqui o órgão/provedor, URL de origem, data de acesso, licença e metadados oficiais assim que forem confirmados.

## Limitações conhecidas

- Período dos arquivos recebidos: janeiro de 2026.
- Os arquivos não declaram explicitamente o fuso horário.
- A documentação recebida não confirma todas as unidades de medida.
- O valor hidrológico 35 requer verificação com documentação do sensor/provedor.
- Duas correspondências geotécnicas com pluviômetros são aproximadas, não exatas.
- Não há limiares oficiais suficientes para produzir alertas de risco validados.

## Decisões para transparência

- Dados brutos são preservados.
- Valores suspeitos são sinalizados e documentados; não são apagados sem justificativa.
- Integrações aproximadas são explicitamente identificadas.
- A interface deve informar período e natureza histórica dos dados.
